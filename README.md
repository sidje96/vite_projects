## commands:

open je opdrachtenprompt
ga naar de juiste folder
of open de juiste folder in vscode, open daarin 2 terminals in de ene 
typ:
```
npm run dev

```
en in de ander:
```
npm run json-server
```
optioneel: 
npm run dev -- --host
zodat je de server ook op andere apparaten kan openen zoals je telefoon
